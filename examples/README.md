# Recorded Orinda prototype day

Open the V4.1 HTML in a fresh browser session with its compact starting layout. Choose Orinda, click **Load replay**, and select `ION_Orinda_Day_1_replay.json`. Press Play, seek, change speed, or select a building. Loading and playback do not post inventory, time or spending.

This recorded nine-hour shift certifies 246 engines and dispatches 194. Undispatched output, station reserves and unfinished work remain accounted for. Opening certified stock is zero. Pre-shift preparation takes approximately five modeled hours. The recording is a model example using the estimated opening-WIP allocation; it is not a measurement or proof of sustainable output. The 247/day source reference for A+B remains separate.

The file is gzip-compressed JSON decoded by the tool. A saved workspace with another layout must be loaded separately before its matching replay. Existing V4 workspace layouts remain supported and can be compacted as explicit proposals.

See `docs/VALIDATION_V4_1.json` for production, labour, costs, conservation and measured calculation performance. Use the compact daily production/labour report and implementation handoff for document updates; the replay is primarily a visual event log.
